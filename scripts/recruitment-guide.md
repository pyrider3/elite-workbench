# 招募表单管理

进入 https://dj.qnjyxh.xyz/，点击上方姓名入口，在弹窗中选择“管理员登录”，用招募管理员密码登录，选择“招募表单”。超级管理员也能使用此栏目。

1. 制作表单：新建或选择草稿，填写标题、介绍。支持短文本、长文本、数字、电话、邮箱、单选、多选、下拉。选项每行一个，字段最多40个，可设必填及上下排序。
2. 预览：只预览、不写入填写结果。保存草稿后选择入口/a至/e，点击发布。每次发布创建一个独立版本并替换该入口当前版本。
3. 五个入口：打开对应地址，查看当前版本的提交数量，暂停/恢复提交，设置北京时间开始与截止时间。不填写时间则持续开放。
4. 收到的结果：筛选表单版本、搜索填写内容、展开详情、导出CSV。CSV每条提交一行、字段一列，按字段标签与类型跨版本对齐，多选用顿号连接，保留完整联系方式。

旧版结果始终保留。编辑草稿不会修改已发布版本。入口替换版本后，填写旧页面的人提交时会收到刷新提示。暂停或过截止时间后服务器拒绝提交。重复提交同一次请求不会新增结果。

所有五个入口共享原服务器与SQLite，不新开服务器端口，不需要新增Cloudflare隧道。新数据使用recruit-form/recruit-version/recruit-route/recruit-response类型，自动随现有每日私有完整备份保存。密码仅以散列存入私有数据库，不写在公开源码中。

每个入口可设置最多收取份数（1至100000，留空不限），按该入口当前已发布版本统计。达到上限停止收取并显示名额已满；提高限额可恢复，重新发布新版本重新统计。并发提交串行校验避免最后一个名额超收，同一次提交重试不额外占名额。

结果列表以姓名为主显示关键字段，点击整条打开详情，完整电话在详情中查看；单页隐藏分页。CSV现为每条提交一行、字段一列，按字段标签与类型跨版本对齐，多选用顿号连接，保留原始完整联系方式。
